# Project Overview

## Introduction

This project focuses on developing a university lecture scheduling system using **Genetic Algorithms (GAs)**.

The main objective is to generate an optimized university lecture timetable while considering available courses, classrooms, and teaching staff.

The algorithm will explore different scheduling combinations to find a solution that satisfies the defined constraints while minimizing scheduling conflicts.

## Main Objectives

- Automate the university lecture scheduling process.
- Minimize scheduling conflicts.
- Optimize classroom and teacher utilization.
- Develop a scheduling solution using genetic algorithms.
- Evaluate the quality of generated timetables.

# Project Tasks

The project is divided into three main tasks.

## Task 1 – Initial Schedule Generation

**Status:** In Progress / Planning

Implement a genetic algorithm capable of generating an initial university lecture timetable.

### Objectives

- Define the input data structures.
- Identify scheduling constraints.
- Generate an initial population of possible schedules.
- Implement the genetic algorithm.
- Generate a valid lecture timetable.

### Input Data

- **Courses:** Available courses and lectures that need to be scheduled.
- **Classrooms:** Available classrooms and their capacities.
- **Teachers:** Available teaching staff and their schedules.
